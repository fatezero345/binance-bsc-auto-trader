# 07 风险与未解决问题

编号规则：`R` = 风险（可能发生、有后果）；`B` = BLOCKED（当前做不了，有明确解除条件）；`D` = 待人工决策。

> ADR-0002 之后重排。风险重心从「私钥泄漏」转到「时钟 / 交易对手 / 权限位」。

## 四、诚实边界

1. **P0 没有产生任何真实交易**，因此本报告没有"策略有效"或"能赚钱"的任何主张。29.30 USDT 仍是任务书里的计划数，不是实测持仓（[03](03-holdings-snapshot.md)）。
2. **风控代码经过 56 条单测，但它防的是"代码写错"，不是"市场会怎样"。** 滑点、深度枯竭、交易所冻结、时钟漂移——这些一个都还没有被真实资金验证过。
3. **时钟偏差是本轮最不该被忽略的发现**：它不是理论风险，是两次采样之间实测 2.6 秒的漂移。任何"先跑起来再说"的判断都应当先看一眼这一条。
4. 本报告的每一个市场数字都能在 `docs/evidence/raw/` 找到原始响应。找不到原始响应的结论，就是没做。
